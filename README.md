# Zepto AI/ML Capstone Project

An end-to-end AI/ML engineering project covering data collection, data analysis, machine learning, GenAI, RAG, LangGraph, FastAPI, and Docker.

## Project Architecture

DATA → ANALYSIS → ML → GENAI → API

### Module 2 — Analytics + Machine Learning

- Regression
- Model pipeline

### Module 3 — GenAI Support Assistant
- Policy documents
- Embeddings
- ChromaDB
- RAG
- LangGraph
- Mock LLM
- FastAPI
- Docker
